# SSW Konstruksi (土木) — CBT Mock Test & Practice Portal

Website latihan dan simulasi ujian **SSW Konstruksi / Teknik Sipil (特定技能1号・建設分野 土木)** berbasis Computer Based Testing (CBT).

## Fitur Utama
- **50 Soal CBT Lengkap**: Sesuai kurikulum resmi `Doboku bab 05.pdf` (*建設機械, 推進トンネル, 海洋土木, さく井, 鉄骨, 鉄筋, 溶接, 型枠, 塗装, 造園*).
- **Format 4 Pilihan (A, B, C, D)**: Mendukung pertanyaan dengan diagram visual dan pilihan jawaban bergambar A–D.
- **Mode Ujian Lengkap (CBT Mode)**: Dilengkapi timer 70 menit, penilaian otomatis, dan lembar evaluasi jawaban.
- **Mode Latihan (Practice Mode)**: Waktu tanpa batas, tombol bantuan Furigana, Terjemahan Indonesia, dan Kosakata (Kotoba) per opsi.
- **Kamus Kotoba Terintegrasi**: 1.890+ entri kosakata teknis konstruksi dengan kanji, furigana, dan arti leksikal.
- **PWA / Offline First**: Dapat diinstal di HP/Desktop dan bekerja offline via Service Worker.

## Lisensi & Atribusi
- Materi soal dan teks diadaptasi dari Buku Panduan Resmi Ujian Keterampilan Spesifik Bidang Konstruksi Jepang (建設分野特定技能評価試験 実技試験テキスト).
